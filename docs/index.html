Projeto P2 · Banco de Dados · Parte 1

Uma plataforma de streaming,
cinco tipos de banco de dados

Cada módulo da plataforma guarda seus dados no tipo de banco que melhor resolve o problema dele. O acervo são clássicos de domínio público do Internet Archive, que tocam de verdade no app.

Como os módulos conversam

O mesmo id do perfil e o mesmo id do título aparecem em todos os bancos: é isso que liga os módulos (ex.: perfil 1 = Mariana, t1 = Nosferatu).
